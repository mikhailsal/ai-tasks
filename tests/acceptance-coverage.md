# Acceptance coverage crosswalk

This is the T106 traceability review for contract/schema v1. It maps implemented behavior
and existing assertions; it is not a new execution report or a substitute for human acceptance.
The governing sources are the [specification](../specs/001-ai-task-manager/spec.md),
[plan verification matrix](../specs/001-ai-task-manager/plan.md#constitution-v300-recheck-and-verification-matrix),
[tasks](../specs/001-ai-task-manager/tasks.md), and
[constitution v3.0.0](../.specify/memory/constitution.md). Paths below are relative to the
repository root. The [mutation ledger](mutation-coverage.md) records command-specific
applicability and historical checkpoints; [query-plan evidence](query-plans.md) records
actual prepared statements, bindings, plans, and query-count bounds.

T001–T105 have reached their owning checkpoints. T106 checks coverage, not merely the
existence of source files. **T107 is still pending**: clean installation, the final composed
production checks, executable quickstart, and separately budgeted benchmark results must be
recorded in `docs/validation.md`. The benchmark harness and fixture checks do not establish
latency-goal attainment. No predecessor release exists, so released-version upgrade/rollback
execution is N/A for v1; internal populated migration checks remain applicable.
